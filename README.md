# Receipt Maker Pro

A premium, offline-first receipt and POS workspace built with React + Vite.

## Included
- Fast POS billing with product catalog
- Receipt history and one-click print
- Business profile
- 58mm / 80mm thermal-print-ready workflow
- Local-first storage with no account required
- Responsive desktop and mobile UI

## Run
npm install
npm run dev

Inspired by modern receipt/POS workflows; all UI and implementation are original.
